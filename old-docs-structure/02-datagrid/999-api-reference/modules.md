### add

▸ **add**(`x`, `y`): `number`

Adds two numbers together.

**`Example`**

Here's a simple example:

```
// Prints "2":
console.log(add(1,1));
```

**`Example`**

Here's an example with negative numbers:

```
// Prints "0":
console.log(add(1,-1));
```
